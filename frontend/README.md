# Frontend Application

This is the React client for the Journal App. It handles zero-knowledge AES-GCM client-side encryption and strict session handoff logic.

## Tech Stack
- **React 18**
- **TypeScript**
- **Vite**
- **TailwindCSS**

## Getting Started

1. Ensure the Node.js (v18+) is installed.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
The UI runs on `http://localhost:5173`.
